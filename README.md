# fares-business-helper
# 💱 حاسبة الصرافة الذكية (عمان - مصر)

تطبيق ويب بسيط ومطور مخصص للصرافين المستقلين والمحولين بين سلطنة عمان وجمهورية مصر العربية باستخدام العملات الرقمية (USDT).

## 🚀 المميزات
* **تحويل تبادلي:** أدخل المبلغ بالريال يحسب الجنيه، أو العكس تلقائياً.
* **دقة عالية:** حساب التكلفة الفعلية بناءً على سعر شراء الـ USDT بالريال (دقة تصل لـ 3 أرقام عشرية).
* **مقياس الربحية:** نظام ذكي يحلل صافي الربح ويصنفه (ممتاز، جيد، مخاطرة، خسارة).
* **خصم العمولات:** خانة مخصصة لعمولة الوسيط لضمان معرفة الربح "الصافي".
* **واجهة Dark Mode:** تصميم عصري مريح للعين ومناسب للعمل الميداني.

## 📱 كيف تستخدمه كـ تطبيق على الهاتف؟
1. افتح رابط الموقع من متصفح كروم على هاتفك.
2. اضغط على خيارات المتصفح (⋮).
3. اختر **"Add to Home Screen"** أو **"إضافة إلى الشاشة الرئيسية"**.
4. سيظهر لك كأيقونة تطبيق مستقلة على هاتفك.

## 🛠 التكنولوجيات المستخدمة
* HTML5
* CSS3 (Dark Theme)
* JavaScript (Vanilla JS)
